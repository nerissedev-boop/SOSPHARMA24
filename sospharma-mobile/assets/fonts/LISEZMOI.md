# Police Vonca

Vonca est la police des titres (licence payante, fichier fourni par le client).
Déposez ici les fichiers, avec exactement ces noms (otf ou ttf) :

- `Vonca-SemiBold.otf` (600)
- `Vonca-Bold.otf` (700)
- `Vonca-ExtraBold.otf` (800)

Puis lancez `npm run polices:detecter` (fait automatiquement par `npm start`).
Sans ces fichiers, les titres utilisent Urbanist (repli prévu par la charte).
